# Web MiniDisc Pro — TE Overhaul Visuals

High-fidelity visual study for a Web MiniDisc Pro interface overhaul, influenced by teenage engineering’s industrial product language.

Open `index.html` for a static gallery, or browse `visuals/` directly.

## Corrections in this series

- **MiniDisc, not CD** — cartridge shells with shutters; rectangular face stickers with dog-ear cut
- **Print pack** — main disc label, edge/index strip, MiniDisc box/case label
- **Deck** — album art is a primary now-playing surface
- **Fork features** — Downtify music library browse + background playlist download queue

## Design notes

- **Palette:** chassis `#F7F5F0` / workshop `#EBE8E2`, ink `#111`, TE orange `#FF4D00`, LCD olive
- **Labels:** main ≈ 36×53 mm dog-ear sticker on cartridge; edge ≈ 59×3.75 mm strip; box/case front for the MD shell case
- **Downtify:** mirrors the fork’s embedded `/downtify/` library (albums/artists/playlists/tracks) and URL queue for background downloads before encode-to-disc

These are **visual mockups only** (not wired into the React app).
