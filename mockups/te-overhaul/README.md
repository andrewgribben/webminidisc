# Web MiniDisc Pro — TE Overhaul Visuals

High-fidelity visual study for a Web MiniDisc Pro interface overhaul, influenced by teenage engineering’s industrial product language: chassis framing, orange status accents, monospace instrument labels, LCD/hardware controls, and sparse modular panels.

Open `index.html` for a static gallery, or browse `visuals/` directly.

## Design notes

- **Palette:** warm chassis `#F7F5F0` / workshop `#EBE8E2`, ink `#111`, TE orange `#FF4D00`, LCD olive
- **Type:** geometric grotesk display + monospace labels
- **New capability called out:** Label Studio exports disc contents/titles into printable graphical labels — cover art for fixed albums, generative faces for mixes

These are **visual mockups only** (not wired into the React app).
